📊 E-commerce Dataset – Exploratory Data Analysis (EDA)

This project contains an Exploratory Data Analysis (EDA) of an e-commerce dataset.
The goal is to understand user behavior, order patterns, revenue trends, and other business insights through data exploration and visualization.

🛠️ Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn
📈 Analysis Included

Data cleaning & preprocessing

Summary statistics

Missing value analysis

User & order behavior insights

Time-based trends (daily / monthly)

Revenue and sales patterns

Visualizations for all major findings

How to Run:-

Install required libraries:

pip install pandas numpy matplotlib seaborn


Open Jupyter Notebook:

jupyter notebook


Run the notebook:
Ecommerce-EDA.ipynb
